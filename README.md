# Facial Recognition Banking System

A secure banking application with facial authentication using Python, OpenCV, and face_recognition library.

## Features
- 👤 User registration with facial data
- 🔓 Secure login using facial recognition
- 🏦 Mock banking dashboard
- 📸 Real-time face detection and capture
- 🎯 Auto-capture when face is stable
- 👥 User management system
